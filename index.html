1. Introduction to Jenkins

Jenkins is an open-source automation server commonly used to implement Continuous Integration and Continuous Delivery (CI/CD).

Continuous Integration

Automatically builds and tests applications whenever developers push changes to a repository.

Continuous Delivery

Automates the process of preparing an application for release.

Automation

Jenkins can automate builds, testing, deployments, and many DevOps tasks.

2. Jenkins Installation

Jenkins can be installed on Linux, Windows, macOS, or run inside a Docker container.

Run Jenkins with Docker

```

docker pull jenkins/jenkins:lts

docker run -d 
--name jenkins 
-p 8080:8080 
-p 50000:50000 
jenkins/jenkins:lts
```

After starting Jenkins, open your browser and navigate to: 

```

http://localhost:8080
```

Jenkins will display an initial setup screen where you can unlock Jenkins and create the administrator account.

3. Jenkins Pipeline

A Jenkins Pipeline defines the steps Jenkins should execute to build, test, and deploy an application.

Example Jenkinsfile

```

pipeline {
agent any

```
stages {

    stage('Build') {
        steps {
            echo 'Building application...'
        }
    }

    stage('Test') {
        steps {
            echo 'Running tests...'
        }
    }

    stage('Deploy') {
        steps {
            echo 'Deploying application...'
        }
    }
}
```

}
```

The pipeline contains three stages:

  • Build
  • Test
  • Deploy

4. Jenkins and Docker

Jenkins can be integrated with Docker to build Docker images and run containers as part of a CI/CD pipeline.

Example Docker Commands

```

docker build -t my-app .

docker run -d 
--name my-app-container 
-p 8080:80 
my-app
```

A Jenkins pipeline can execute these commands automatically after code is pushed to GitHub.

5. Useful Jenkins Concepts

Job

A Jenkins job defines a task Jenkins should perform.

Pipeline

A pipeline defines an automated workflow for building, testing, and deploying software.

Agent

An agent is a machine or environment where Jenkins executes tasks.

Jenkinsfile

A text file that stores the pipeline configuration as code.

Common Docker Commands for Jenkins

```

docker ps

docker images

docker logs jenkins

docker stop jenkins

docker start jenkins

docker restart jenkins

docker rm jenkins
```

6. Typical CI/CD Workflow

  1. Developer writes code.
  2. Code is pushed to GitHub.
  3. Jenkins detects the change.
  4. Jenkins builds the application.
  5. Automated tests are executed.
  6. Docker image is built.
  7. Application is deployed.

7. Jenkins Best Practices

  • Store pipeline configuration in a Jenkinsfile.
  • Keep Jenkins credentials secure.
  • Use version control such as GitHub.
  • Automate testing before deployment.
  • Use Docker to provide consistent build environments.
  • Monitor Jenkins jobs and build results.
